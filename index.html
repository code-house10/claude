Lara Translate settings

Puter AI is now the main subtitle translator. Lara is kept only as a backup/test option in case you still want to check it later. Lara settings are saved locally and synced to Supabase so they can be restored on your other devices.

If Lara returns a quota error, ignore it unless you choose to use Lara manually. Subtitle translation now uses Puter AI first, then MyMemory fallback.

OpenRouter AI Settings

OpenRouter is now available for subtitle translation and template examples. The app uses free models only. Recommended model: openrouter/free. If OpenRouter fails or has rate limits, Puter AI and MyMemory remain as fallbacks.

For safety, this app refuses non-free models. Leave the model empty or write free to use OpenRouter's free router.
